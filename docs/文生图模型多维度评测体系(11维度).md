# 文生图模型多维度评测体系\(11维度\)

调研日期：2026 年 10 月 10 日

# 一\. 调研背景与目标

文生图模型的能力并不等同于单一的图文相似度。实际业务评估需要同时判断指令是否被理解、主体和空间关系是否正确、视觉质量是否稳定，以及风格、创意、文字、产品表达等更细粒度要求是否得到满足。现有表格已把这些要求拆解为一级维度、二级维度、评测规则与固定 Case，为建立统一评测体系提供了基础。

本调研的目标是：在不推倒现有 Case 表的前提下，明确不同维度可采用的技术路线，形成统一的评分与结果记录原则，并给出后续验证与集成工作的优先级。报告将“已完成的维度设计”“调研得到的候选技术”“尚未验证的评分方案”严格区分。

# 二\. 现有评测方案调研

现有公开方法可按能力边界组合使用。GenEval 与 T2I\-CompBench 适合检查可枚举的属性、数量、关系与组合约束；TIFA 及 Soft\-TIFA 将提示词拆解为可回答的问题，便于定位失败原因；VQAScore 以视觉问答概率衡量图文对齐；ImageReward 与 PickScore 反映偏好排序信号。它们均不能单独覆盖创意或艺术表达，因此需要与人工标注和专用视觉信号配合。

|**方法**|**主要能力**|**优势**|**主要局限与建议定位**|
|---|---|---|---|
|GenEval   / T2I\-CompBench|属性、数量、关系、组合约束|规则明确、可批量复现|不能覆盖开放式审美与创意；适合作为客观规则检查。|
|TIFA   / Soft\-TIFA|将提示词拆为 VQA 问题|结果可解释，便于定位主体或关系错误|问题生成和答案规范会影响分数；应固定模板并抽检。|
|VQAScore|整体图文对齐与主题关联|可补足复杂语义匹配|依赖 VQA 模型能力；应与硬约束分开记录。|
|ImageReward   / PickScore|人类偏好代理与候选排序|适合初筛和排序|不是客观真值；不应直接命名为创意或美学准确率。|
|CLIP   / DINOv2 / LPIPS|语义匹配、特征相似、感知距离|本地批量、可复现，适合基线|只能测代理信号；不能单独证明风格正确或具有创意。|

# Benchmark 标准

所有适用维度统一采用 1–5 分制，不再为每个维度分别制定不同评分标准：

|**分数**|**定义**|
|---|---|
|**5分｜优秀**|完全符合要求，无明显问题，可直接使用|
|**4分｜良好**|基本符合要求，存在轻微瑕疵，但不影响理解和使用|
|**3分｜合格**|部分符合要求，存在明显问题，需要修改后使用|
|**2分｜较差**|偏离要求较多，影响主体表达或画面使用|
|**1分｜失败**|核心要求未实现，存在严重错误，画面基本不可用|

# 2\.主体结构与比例

主体结构质量适合采用“专用结构信号优先、VLM 复核兜底”的路线。人体、手足和姿态可由人体姿态/手部关键点模型输出可计算的关节、骨架和缺失率；动物、物体及产品结构可结合类别检测、分割和关键部件规则。真实感或偏好模型只能辅助排序，不能替代结构正确性判定。

# 4\.视觉质量与真实感

本类应将技术性质量与审美/真实感分开记录。清晰度、噪点、边缘完整性、局部伪影可使用无参考图像质量、模糊和分割连续性等信号；材质、主体背景融合和自然度则需要视觉问答、偏好模型或人工判断。任何偏好模型的结果均应保留为排序或辅助信号，不能替代对伪影和结构错误的明确记录。

# 7\.多主体与交互关系

本类的前提是为每个主体建立稳定的实例 ID。应先检测并分割人物、动物或物体，再把 Prompt 中的主体、属性、位置和互动要求绑定到对应实例。计算结果必须保留“哪个实例被判定为哪个主体”的映射，避免只凭全图相似度掩盖身份混淆。

# 8\.物理与状态合理性

# 五\.评分与结果汇总

建议所有可评分 Case 统一落到 1 至 5 分，同时保留原始模型输出、判定理由、失败标记和适用状态。分数汇总采用分层**加权平均**：Case 汇总为二级维度，二级维度汇总为一级维度，一级维度再汇总为总分。

尚未跑满时，不应把部分结果当作完整成绩。应同时输出部分加权分、权重覆盖率、Case 完成率与状态。未运行、运行失败和不适用必须分开记录；只有共同完成的 Case 才可用于临时横向比较。二级维度权重在人工校准完成后再冻结，并保持对全部被测模型一致。

# 六\.可行性与风险分析

|---|---|---|
|自动评分误差|代理指标可能与人工判断偏离|建立每维度 20 至 50 个样本、2 至 3 名盲评者的校准集，计算相关性与一致性。|
