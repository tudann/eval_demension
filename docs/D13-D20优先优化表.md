## 本轮先做哪一块

**先做 D14：局部修改 + 非目标保持。**

对应 StreamEval 的 Edit Success 和 Preservation。现在几乎是一道印象题，闪一下改对也能高分。改的是 `facts` 和检查题，不必先上新模型，也不必复现流式评测。

本轮只按 StreamEval 能直接改题的顺序走：

1. **D14** Edit Success + Preservation（最先）
2. **D20** Following（表演指令是否做到）
3. **D16** A–V Sync（只改题面口径：相关与偏移窗；本轮不接别的同步实现）
4. **D14 参考编辑** Reference / Identity（参考属性是否生效、身份是否保住；仍写在 D14 题面上）

D13、D15、D17、D18 在 StreamEval 里没有可直接搬的检查点，本轮不改。

## 第 1 步具体改什么（只动 D14）

短 clip 不必按时下发指令，只保留检查点形状：

1. 出题抽出：期望状态（要改成什么）+ `protected`（不许动什么）。
2. 检查题成对：目标是否在稳定段成立；保护内容是否未改。
3. 小样本和人工分对照，同向后再考虑进正式权重。

形状来源：StreamEval 指令编辑 case `sa.v1.001.instruction_edit`（上衣 A→B→A，检查窗口 + 保护列表）。短视频只留「稳定段 + 保护列表」。
