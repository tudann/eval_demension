# 18维度评测体系（07\-12）

# 一\. 调研背景与目标

视频生成模型的能力不能仅用单帧画质或整体图文相似度衡量。实际业务评估还需要判断物理过程是否合理、场景空间是否连续、镜头是否遵循指令、摄影语言是否正确、多主体身份与属性是否稳定，以及实际输入参考中的关键信息是否得到保持。

现有 Case 表已将这些要求拆解为一级维度、二级维度、评测规则与固定 Case。本项目在保留既有编号、规则和 Case 的基础上，围绕第07–12维建立统一接入、独立测量、证据追溯与分数汇总流程。

本调研的目标是明确不同维度的技术路线与能力边界，形成统一评分和结果记录原则，并确定后续验证与集成优先级。报告严格区分“维度与规则已设计”“受限原型已实现”“工程流程已验证”和“真实测评准确性已验收”。

# 二\. 现有评测方案调研

公开方法各有侧重，需要按维度组合使用。现有方法的原始指标与本项目47项细则并非逐项等价，因此需要在对应框架内继续细化。

本报告覆盖18维总体体系中的07–12部分，共 **6个一级维度、47个二级方向**。
