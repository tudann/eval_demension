# D14 StreamEval 检查点对照实验报告

## 1. 实验结论

这次优化只改 D14 交给裁判的两道核心题：**局部修改准确性**、**非目标区域保持**。改的是题怎么写、看哪一段。对照同一批 18 条清单后，优化后的出题方式优于优化前：题意更清楚、时间范围更清楚、两道核心题配对更完整。

改法来自 StreamEval 的 Edit Success 与 Preservation：一句终态、一份保护列表、同一时段。门槛题未改。主体替换、增删、延长、首尾帧适用时仍可出题，但不在本报告展开。不评价成片，也不比较维度分。

## 2. 借鉴与改法

只借检查点形状，不引入会话、毫秒时限或 0–100 聚合。

| 借鉴点 | 落到这两道题 |
|---|---|
| Edit Success | 局部修改写成：期望状态是否在成片后段连续稳定；闪一下、改错对象、旧状态回来不算充分达成 |
| Preservation | 非目标写成：同一时段，保护列表是否未改 |

优化后这两道题固定为核心。清单里的时间提示不写具体起止秒，「成片后段稳定段」是给裁判的文字范围。

## 5. 结论

对照 18 条清单后，可以认定：优化后的出题方式优于优化前。

1. **题意更清楚。** 局部修改固定问一句终态是否成立，非目标固定问一份物体与外观列表是否未改。裁判不再面对「逐渐拉紧」「两次敲击」「步进到位」这类混在一起的过程印象题。
2. **时间范围更清楚。** 两题都从「全片」收到「成片后段稳定段」，并且非目标题明确与终态同一时段。裁判知道该核对准哪一段画面上的结果，而不是整段过程里的每一步。
3. **两道核心题配对更完整。** 优化前有 3 条缺局部修改题，非目标题的保护范围也不统一；优化后 18 条都是「终态 + 保护列表」成对出现，交给裁判的检查点形状一致。

因此，就「交给裁判的核心题怎么写、看哪一段」而言，StreamEval 风格的终态检查点比原先的自由出题更适合 D14 这两项子点。本结论只针对出题协议，不涉及成片或生成模型的好坏。
