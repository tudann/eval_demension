# 视频生成模型七维评测体系（D13–D18、D20）

更新日期：2026 年 10 月 19 日。第一、二节综述公开评测方法和本调研要回答的问题；从第三节起描述当前代码。二级子项以 `data/d13_d20_cases.csv` 为来源，以 `configs/dims_13_18.yaml` 为执行配置。D19 不属于本评估框架。

# 一. 调研背景与目标

早期视频生成评测沿用图像和视频理解里的分布指标，例如 Inception Score 和 Fréchet Video Distance。它们比较一批生成视频和一批真实视频的整体分布，能反映多样性和画质倾向，看不出某一条提示词里的风格、编辑、对白、字幕或表演有没有做到。CLIP 图文相似度把整段视频收成一个对齐分，同样盖不住这些分开的要求。

随后的公开基准开始拆维度。VBench 把文生视频拆成主体一致、背景一致、闪烁、运动平滑、动态程度、美学、成像、物体类别、颜色、空间关系、场景、外观风格、时间风格和整体一致性等十多项，每项用专门模型。EvalCrafter 从视觉、内容、运动和文视频对齐四组共十余个客观指标打分，再用人工意见拟合系数。FETV 按内容、可控属性和提示复杂度组织人工细评。T2V-CompBench 专看属性绑定、空间关系、动作绑定和数量等组合能力。VideoScore 则训练多模态模型，按画面质量、时间一致性、文视频对齐和运动质量模拟人工细评。音视频生成工作另借语音增强、说话人识别和口型对齐里的指标，例如 DNSMOS、ECAPA、CLAP、SyncNet 的 LSE-C / LSE-D。

这些拆分仍然对不齐本报告要覆盖的七件事：风格和光照色彩是否按要求站住，编辑是否只改该改的地方，对白和声音是否正确，口型与动作音是否同时发生，人体和主体是否崩坏，画面文字和字幕是否正确，人物情绪和表演是否成立。外观风格分多半是提示词和帧的相似度，编辑保真、字幕错字、台词内容和表演时机在上述基准里很薄，或者根本没有对应维度。

本调研的目标是把公开方法按这七个问题归位，写清每类方法实际量到的量，以及它和 39 个二级子项之间的差距。后文的清单、门槛和数值组件只采纳对得上的部分。报告区分“公开方法已经在测相近的量”“该指标测的是另一件事”和“本项目子项尚无直接的公开自动指标”。D19 的成本类指标不在这次调研范围内。

# 二. 现有评测方案调研

公开方案大致分成三条：数据集级的分布分，按固定维度调用专门模型，以及用多模态模型按提示词打分。下表只综述这些公开方法。本仓库的开关、权重和阈值从第三节起说明。

|**方法**|**主要评什么**|**和这七维的关系**|**不能直接当成的结论**|
|---|---|---|---|
|IS、FVD|一批生成视频相对真实视频的多样性与分布距离|可作模型级画质和多样性的背景参考|某一条提示词的风格、编辑、音频、字幕或表演是否成功|
|VBench|主体与背景一致用 DINO、CLIP；闪烁用帧差；运动平滑借用插帧先验；动态程度用 RAFT；美学用 LAION 预测器；成像用 MUSIQ；颜色和物体用检测或描述模型；外观风格用 CLIP 图文相似度；时间风格用 ViCLIP|风格、颜色、主体漂移和画面崩坏有相近信号。主体一致和闪烁可辅助失败与异常|外观风格分证明参考图风格被保持；时间风格分证明镜头指令；它没有编辑保真、对白、口型、字幕和表演维度|
|VBench-2.0|在画质和语义之外增加人体保真、物理、常识等忠实度，并用多道是否题让视觉语言模型作答|人体畸变、常识性失败有更接近的问法|异常发生率或持续秒数；情绪、视线和台词表演|
|EvalCrafter|视觉、内容、运动、文视频对齐；含光流扭曲误差、相邻帧 CLIP、人脸一致、动作分类和平均光流，再对人工意见做回归|人脸一致可辅助身份漂移；动作分类可看常见人体动作是否出现|人脸一致等于人物替换成功；Kinetics 动作类别等于指定表演或对白|
|FETV|按内容、可控属性和提示复杂度做人工细评|说明同一总分会掩盖不同失败类型|可复用的风格、编辑、音频或字幕数值组件|
|T2V-CompBench|属性绑定、动态属性、空间关系、动作绑定、物体交互和数量；用多模态模型、检测和跟踪|属性是否串到错误物体、主体关系是否稳定，和失败、编辑里的部分要求相近|风格控制、声音、同步、字幕和情绪表演|
|VideoScore|多模态模型按画面质量、时间一致性、文视频对齐、运动质量打分|提示词里写明、固定指标覆盖不到的要求，可以用模型逐条判断|字符错误率、声纹相似度、口型偏移或字幕是否多出来|
|CLIP、ViCLIP|帧或短视频与文本的余弦相似度|风格词、整体语义是否出现|风格化之后主体和动作还在；光照、色彩是否就是指定的那一种|
|PSNR、SSIM、LPIPS|有参照帧时的像素误差或感知距离。视频编辑、插帧论文常用|首尾帧是否贴住条件图，续写接缝是否突兀|像素接近等于编辑意图正确；没有参照帧时没有意义|
|ArcFace 及同类人脸特征|人脸嵌入余弦相似度。说话头和视频编辑论文用它看身份保持|人物替换后是不是同一张脸，跨帧脸是否漂移|物体替换、服装和动作是否合理；画面里没有脸时没有身份结论|
|DNSMOS|无参考语音质量，输出信号、背景和整体听感分。来自语音增强，也被音视频生成评测借用|可听人声是否自然、有没有明显合成噪声|环境音、动作音效、配乐，以及表情和姿态|
|ECAPA-TDNN|说话人嵌入。两段语音的余弦相似度用于同一人判断|同一角色重复说话，或和参考声比对，是不是同一人|非语音音色；可用语音段不足两段时没有结论|
|emotion2vec 及语音情绪分类|语音情绪标签或嵌入是否贴近目标情绪|提示词写明的语气、语调|面部表情、视线、肢体是否同时表达该情绪|
|CLAP、FAD、PANNs|CLAP 衡量音频和文本的相似度；FAD 比较生成音频与参考集合的分布；PANNs 做声音事件标签，例如音乐|环境声、动作声、配乐是否像描述|声音是否和画面同一时刻发生；FAD 不能给单条提示词一个事件级结论|
|SyncNet（LSE-C、LSE-D）|可见嘴部与语音的同步置信度和距离。Wav2Lip 等工作用它报告口型|有语音且脸可见时，口型是否对齐|动作音、环境音是否同步；画外音、嘴部不可见时不能解释成口型失败|
|Synchformer、AV-Align|一般音画时间偏移，或音频能量与画面变化的起始对齐|动作声、环境声是否跟画面变化落在相近时刻|提示词点名的那一件事是否对上；偏移小不等于事件语义正确|
|Whisper 等识别后的字词错误率|语音转写和指定对白的差异|对白内容是否说对|声音自然、音色一致，或说话的人是不是画面里的那一个|
|OCR 与字符错误率|检测并识别画面文字，再和目标字符串比较。图像文字生成论文常用；视频基准里很少单列字幕维|错字、漏字、乱码可以离开整体印象单独记录|口播台词等于画面文字；艺术字、强透视和闪烁字幕的识别可靠|

这些原始指标和本项目 39 个二级子项不是逐项等价。视线、微动作、台词与表演是否同一意思，以及异常的持续秒数，公开自动指标里基本没有直接对应。后文只把对得上的量放进数值组件，其余要求交给按提示词生成的检查题。

# 四. 评测技术方案

## Benchmark 标准

适用的检查题统一用 1–5 分，不再为每个维度另写一套分数含义：

|**分数**|**定义**|
|---|---|
|**5分｜优秀**|要求完全达到，结果自然、稳定，几乎看不出问题|
|**4分｜良好**|核心要求达到，只有轻微或局部偏差，不明显影响观看|
|**3分｜合格**|要求基本达到，但仍有明显问题、遗漏或不自然|
|**2分｜较差**|要求只达到一部分，错误、缺失或不稳定已经影响内容是否成立|
|**1分｜失败**|要求基本没达到，或结果严重损坏、不可用|

一道检查题的 5 分表示题面要求完全达到。当前生成器只接受 `rubric_5` 检查题，不接受旧的是非题作为新清单。门槛题仍回答“是/否”，不套五档表；任一门槛明确失败，该维记 1.0 分。

检查题每个适用子项恰好一道，核心题最多 3 道；多出来的核心标记会降为非核心，不因此整份作废。缺任一适用子项时整份清单无效，并按维度重出一次：第 16 维先把空事实或“是否同步”类事实改回提示词里的声音，仍无效时用 temperature 0.4 重出，再不行则按提示词里的声音生成清单；第 18 维重出一次，若仍把口播写成画面文字，则只保留“无要求字幕”题；第 20 维在校验前用题目和提示词引号补上留空的事实；其余维度用 temperature 0.4 重出一次。题目漏答时，该子项最高 3 分。已启用的数值组件返回 `not_configured` 或 `error` 时，不将缺失权重重新分给清单，清单分最高 4 分；任务里显式关闭的组件不触发这一封顶。成功的组件按配置权重加权。数值分只在该子项的检查题被标成核心时进入核心分；非核心子项的低分只把维度分从 5 降为 4，不能单独把维度分打到 4 分以下。维度分按最差核心子项封顶；没有核心题时，非满分的适用子项会把维度分从 5 降为 4。若没有任何可用子项分，则维度不出分。对外公布的是这个维度分。

门槛：主体是否全程清楚；画面是否连续、可以判断。裁判：视觉。

# 14. 编辑与可控生成能力

这一维只评提示词或输入模式里真正存在的编辑和可控要求。局部修改看目标是否改对，非目标区域默认要保持。人物替换可辅以人脸身份；续写和首尾帧在有参照画面时用感知距离和峰值信噪比。没有端点素材时不出首尾帧题。

门槛：要编辑的主体是否清楚；画面是否足以比较编辑前后。裁判：视觉。

固定回归 18 条全部出分，无门槛失败。维度均分 4.144：t2va 4.167（6 条），f2va 3.933（3 条），fl2va 4.000（1 条），r2va 4.225（8 条）。

# 20. 人物表演与情绪表达

这一维同时看表情、姿态、语气和台词。六项标准是：表情、姿态、语气是否符合指定情绪和人物处境；情绪变化有没有合理过渡；视线是否看向正确对象；眨眼、呼吸、头部微动是否自然；听到台词、被触碰或看到事件后的反应是否符合剧情和时间；对白、表情、肢体是否表达同一种意思。

没有指定情绪或处境时，不出情绪准确性。没有表情变化、视线对象、触发事件或台词时，对应项不适用。只要有人物，就检查微动作。当前六项都只有清单，没有单独的表情或视线数值模型。出题不派生风格、编辑、文字或纯镜头题。事实留空时，只用本维题目和提示词里的引号台词补事实，不改其他维。作答抽帧和参考图只在本维按长边不超过 640 缩小，其他维仍按宽度 640 缩放。

门槛：要判断的人物是否清楚；表演和时间关系是否连续。裁判：音画。

# 五. 评分与结果汇总

单条 case 先在内部得到适用子项分，再按第四节的核心封顶规则收成一个一级维度分。批次均值、分模式均值都只统计这个维度分。二级子项分留在该 case 的 `result.json` 里，不另做一套 case 级排名。不适用、缺视频、缺参照、依赖未配置和组件报错分开记录：缺视频不产生分数；已启用数值组件但返回 `not_configured` 或 `error` 时，清单分最高 4 分。门槛失败的维度记 1.0，并进入批次均值。

批次汇总应只对共同完成、状态相同且使用同一套配置的 case 比较。固定回归已对 `data/固定回归case` 的 117 条完成作答和计分，七个维度均分见第三节。第三节维度均分及本节各表中的二级子项均分均来自同一套成片的裁判输出，尚未与人工盲评基准或第二版模型对照，不能据此判断绝对准确性或两版模型的区分能力。

每条 case 的结果落在 `<output_dir>/runs/<run_name>/<dimension_key>/<input_id>/<case_id>/`，包括 `facts.json`、`checklist.json`、`answers.json` 和 `result.json`；批次汇总写在 `<output_dir>/runs/<run_name>/summary.json` 等文件中。更换提示词、视频或评估定义后，应使用 `--force` 重新生成缓存。

# 六. 可行性与风险

|**风险**|**影响**|**控制措施**|
|---|---|---|
|裁判打分偏离人工|同一条轻微瑕疵可能被打成 4 或 5，严重错误也可能被放过|每个已启用维度先做小规模盲评，对照 1–5 分定义计算一致性后再扩大|
|数值组件未配置或报错|已启用但返回 `not_configured` 或 `error` 时，对应子项最高为 4；任务显式关闭组件时不触发该限制|记录每个组件的 `status` 和开关状态；不同配置的批次不混排名|
|D17 暂无实测异常率|“率”和“持续时间”只得到 1–5 分清单评分，不能报告百分比或秒数|在结果解释中标明评分依据；数值统计组件经实现和验证后再考虑接入|

|模型和模板漂移|换裁判、提示词或子项定义后，旧题分数不能横比|记录裁判模型与清单版本；修改输入后用 `--force` 重跑，不混用旧结果|
|成片缺失|有题无分，容易把出题完成当成评测完成|正常运行会在就绪检查阶段报告缺失并停止，不补默认分|
