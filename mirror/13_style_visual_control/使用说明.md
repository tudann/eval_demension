# 第 13 维度评估镜像使用说明

镜像只包含第 13 维度（`13_style_visual_control`）的评估代码、ffmpeg 和 CLIP ViT-L/14。换机器时不需要再配置数值组件。出题模型和视觉裁判仍在镜像外单独启动，本维度这两步用的是同一个视觉模型。

## 文件

| 文件 | 作用 |
| --- | --- |
| `d13-style-eval.tar` | 可 `docker load` 的镜像，标签 `d13-style-eval:13` |
| `run.sh` | 导入镜像并启动一次评估 |
| `task_d13_container.yaml` | 容器内默认任务配置的副本 |
| `Dockerfile` | 以后重建镜像时使用 |

## 使用前

1. 目标机器已安装 Docker，并且能使用 GPU（`nvidia-container-toolkit`）。
2. 视觉模型已经拉起。当前服务地址是 `http://127.0.0.1:18013/v1`，模型名是 `Qwen3-VL-32B-Instruct-FP8`。
3. 准备好 case 目录。挂进容器的目录下必须直接有这四个子目录：

```text
13_style_visual_control/
  t2va/<case_id>/prompt_final.txt
  t2va/<case_id>/video.mp4
  f2va/<case_id>/prompt_final.txt
  f2va/<case_id>/video.mp4
  f2va/<case_id>/input_01.*
  fl2va/<case_id>/input_01.*
  fl2va/<case_id>/input_02.*
  r2va/<case_id>/input_01.* ... input_08.*
```

固定回归集对应：

```text
eval_dem_13_20/data/固定回归case/13_style_visual_control
```

某个模式没有 case 时，不要留空目录以外的结构；四个模式目录都要存在，否则任务会报缺少输入。

## 启动

在本目录执行。`run.sh` 每次都会先 `docker load`，已经导入过也可以直接用。

```bash
cd /keyan/research-eval-group/lt_self/eval_dem_13_20
D13_DATA="$PWD/data/固定回归case/13_style_visual_control" \
D13_OUTPUT="$PWD/outputs/d13_image" \
  bash mirror/13_style_visual_control/run.sh
```

结果写到 `D13_OUTPUT/runs/d13_container/`，汇总看其中的 `summary.md`。

改过打分规则或要忽略已有缓存时加上 `--force`：

```bash
D13_DATA="$PWD/data/固定回归case/13_style_visual_control" \
D13_OUTPUT="$PWD/outputs/d13_image" \
  bash mirror/13_style_visual_control/run.sh --force
```

裁判不在默认端口时，先设置这两个变量再运行：

```bash
export V_EVAL_CHECKLIST_URL=http://127.0.0.1:18013/v1
export V_EVAL_VISION_JUDGE_URL=http://127.0.0.1:18013/v1
export V_EVAL_CHECKLIST_MODEL=Qwen3-VL-32B-Instruct-FP8
export V_EVAL_VISION_JUDGE_MODEL=Qwen3-VL-32B-Instruct-FP8
```

脚本使用 `--network host`，所以容器里的 `127.0.0.1` 就是宿主机。

## GPU

`run.sh` 固定使用宿主机 0 号卡：`--gpus device=0`。这块卡在容器里会被看成 `cuda:0`，CLIP 也跑在 `cuda:0`。

要换卡，改 `run.sh` 里的 `device=0`。不要把 `V_EVAL_CLIP_DEVICE` 设成宿主机的物理卡号；容器里只能看见被分配进来的那一张，编号从 0 开始。

## 只导入、不立刻评估

```bash
docker load -i d13-style-eval.tar
docker run --rm --network host --gpus '"device=0"' \
  -e V_EVAL_CHECKLIST_URL=http://127.0.0.1:18013/v1 \
  -e V_EVAL_VISION_JUDGE_URL=http://127.0.0.1:18013/v1 \
  -e V_EVAL_CHECKLIST_MODEL=Qwen3-VL-32B-Instruct-FP8 \
  -e V_EVAL_VISION_JUDGE_MODEL=Qwen3-VL-32B-Instruct-FP8 \
  -e V_EVAL_CLIP_DEVICE=cuda:0 \
  -v /path/to/13_style_visual_control:/data:ro \
  -v /path/to/outputs:/outputs \
  d13-style-eval:13
```

容器入口是 `run.py`。默认任务配置是 `/opt/d13-eval/configs/task_d13_container.yaml`，数据根目录是 `/data`，输出目录是 `/outputs`。
